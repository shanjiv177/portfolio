Developed the official ticketing and registration platform for Hamfest 2026 facilitating seamless online ticket sales.

- Integrated Razorpay and IRIS Payment Gateway to securely process transactions for the end-to-end ticketing workflow.
- Built an admin dashboard featuring automated QR code check-ins, significantly streamlining on-site event operations.
- Leveraged Next.js, TailwindCSS, and Strapi to build a highly responsive and manageable platform, served via Nginx.
